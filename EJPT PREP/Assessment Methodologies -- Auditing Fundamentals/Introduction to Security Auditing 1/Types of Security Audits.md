Security audits differ based on **who performs them** and **what they focus on**.

---

### **1. Internal Audits**

- **Objective:** Done by the **organization’s own team** to check security controls and policies.
    
- **Importance:** Gives management a self-check before outsiders find issues.
    
- **Example:** A bank’s IT team checks if only authorized staff can access customer loan data.
    

---

### **2. External Audits**

- **Objective:** Done by **independent third parties** for unbiased evaluation.
    
- **Importance:** Provides credibility and benchmarks against industry standards.
    
- **Example:** An e-commerce company hires an external firm for **PCI DSS audit** (credit card security).
    

---

### **3. Compliance Audits**

- **Objective:** Ensure compliance with **laws and regulations** (e.g., GDPR, HIPAA, PCI DSS).
    
- **Importance:** Avoids legal penalties and builds trust with regulators/customers.
    
- **Example:** A hospital undergoes a **HIPAA audit** to ensure patient data is protected.
    

---

### **4. Technical Audits**

- **Objective:** Assess **technical controls** like firewalls, servers, operating systems, and configurations.
    
- **Importance:** Finds weaknesses in system settings and infrastructure.
    
- **Example:** A technical audit checks firewall rules to see if insecure ports are open.
    

---

### **5. Network Audits**

- **Objective:** Focus on **network infrastructure security** (routers, switches, firewalls).
    
- **Importance:** Identifies weak network designs or insecure protocols.
    
- **Example:** A company audit finds sensitive data is being sent via **FTP (insecure)** instead of SFTP.
    

---

### **6. Application Audits**

- **Objective:** Check **software security**, including code, input validation, authentication, and data handling.
    
- **Importance:** Prevents attacks like SQL Injection and XSS.
    
- **Example:** An application audit finds a **SQL injection flaw** in the company’s customer login portal.
    

---

✅ **Quick Memory Tip (Audit Types):**

- **Internal** = Done by own team.
    
- **External** = Done by outsiders.
    
- **Compliance** = Legal/standards check.
    
- **Technical** = Infrastructure focus.
    
- **Network** = Routers, firewalls, design.
    
- **Application** = Software security.
