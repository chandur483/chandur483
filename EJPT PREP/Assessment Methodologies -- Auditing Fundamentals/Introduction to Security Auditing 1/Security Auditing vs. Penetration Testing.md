# **Security Auditing vs. Penetration Testing**

Both are **security assessments**, but they differ in **purpose, scope, and outcomes**.

---

### **🔎 Security Audit**

- **Purpose:** Checks if an organization’s **policies, processes, and controls** are effective and compliant with laws/standards.
    
- **Scope:** Very broad → policies, procedures, documentation, configurations, even physical security.
    
- **Method:** Review documents, interview staff, check compliance, sometimes light technical testing.
    
- **Outcome:** Finds **gaps in rules and processes** → recommends improvements.
    
- **Example:** A **hospital** undergoes a HIPAA security audit → auditors check policies for protecting patient data, employee access controls, and encryption standards.
    

---

### **💻 Penetration Test (Pentest)**

- **Purpose:** Simulates **real-world cyberattacks** to find and exploit vulnerabilities.
    
- **Scope:** Narrower → focuses on systems, apps, or networks chosen for testing.
    
- **Method:** Use hacking techniques, tools, and exploits (like SQL injection, privilege escalation).
    
- **Outcome:** Finds **technical weaknesses** → shows how an attacker could break in.
    
- **Example:** The same hospital hires a pentester → they exploit a vulnerable web app to steal dummy patient data and show management how it could happen.
    

---
