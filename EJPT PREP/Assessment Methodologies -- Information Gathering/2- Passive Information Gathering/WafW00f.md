WafW00f is an **open-source tool** used to **detect and identify Web Application Firewalls (WAFs)** that protect a target website. It works by sending crafted HTTP requests and analyzing the responses to determine whether a WAF is present and, if so, which vendor/product it is.

COMMAND:

```
wafw00f HACKERSPLOIT.ORG -a
```


Possible output:
```
[*] Checking https://example.com
[+] The site https://example.com is behind Cloudflare (Cloudflare Inc.)
```
