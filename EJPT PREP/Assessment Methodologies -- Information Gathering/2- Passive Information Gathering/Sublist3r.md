Sublist3r is an open-source subdomain enumeration tool that gathers subdomains of a target domain using passive OSINT sources (search engines, certificate transparency logs, DNS records, etc.) and optional brute-force. It outputs a list of discovered hostnames you can test further.

# basic usage 
```
sublist3r -d example.com 
```
