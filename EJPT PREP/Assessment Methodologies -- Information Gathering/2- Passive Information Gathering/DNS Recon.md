### Summary Table

|Record|Purpose|Simple Analogy|
|---|---|---|
|**A**|Maps a domain to an **IPv4 address**.|The main phone number.|
|**AAAA**|Maps a domain to an **IPv6 address**.|The new, longer phone number.|
|**NS**|Specifies the **DNS servers** for a domain.|Which phonebook to use.|
|**SOA**|Contains **admin info** for the DNS zone.|The copyright page of the phonebook.|
|**MX**|Directs **email** to the correct servers.|The address of the mailroom.|
|**TXT**|Holds **text data** for verification/security.|A public bulletin board.|
|**SRV**|Points to a **specific service** and port.|A phone number _and extension_ for a department.|
